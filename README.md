# Голос

by Okulovsky · Mac с Apple Silicon: **1.7.7 (23)** · Intel Mac и Windows: **1.7.3**

Локальная диктовка на русском с английскими терминами. Whisper large-v3-turbo
и Silero работают на компьютере. Модели включены: интернет при диктовке,
API-ключи и подписка не нужны. Аудио не сохраняется.

## Установить

[![Установить на Mac](shared/install-mac.svg)](https://github.com/kurgaan5/golos/releases/download/v1.7.7/Golos-1.7.7-macOS-AppleSilicon.dmg)
[![Установить на Windows](shared/install-windows.svg)](https://github.com/kurgaan5/golos/releases/download/v1.7.3/Golos-1.7.3-Windows-x64-Setup.exe)

**Mac:** M1, M2, M3, M4 и новее, macOS 14+. **Windows:** обычный ПК с Intel/AMD,
Windows 10 (2004+) или Windows 11, 64 бита.

Другой процессор: [Mac с Intel — 1.7.3](https://github.com/kurgaan5/golos/releases/download/v1.7.3/Golos-1.7.3-macOS-x86_64.dmg)
· [Windows ARM64 — 1.7.3](https://github.com/kurgaan5/golos/releases/download/v1.7.3/Golos-1.7.3-Windows-arm64-Setup.exe)
· [Все версии и ZIP-архивы](https://github.com/kurgaan5/golos/releases).

Обновление сначала выходит для Mac с Apple Silicon. Ссылки Intel и Windows
ведут к сохранённой 1.7.3, пока новые сборки для них не выпущены. Linux,
Windows 7/8 и 32-битные системы пока не поддерживаются.

### На Mac — 3 шага

1. Откройте скачанный DMG и перетащите **«Голос»** в **«Программы»**.
2. Запустите «Голос». Разрешите микрофон и включите приложение в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
3. Щёлкните в нужном поле и коротко нажмите **правый ⌘**. Диктуйте. Тем же нажатием остановите запись.

Сборка имеет временную подпись, без сертификата Apple и нотариализации.
macOS может предупредить о неизвестном разработчике. После попытки запуска
проверьте раздел «Конфиденциальность и безопасность» и доступное действие
«Всё равно открыть». На управляемом рабочем Mac установка и доступы зависят
от политики компании: запуск без администратора гарантировать нельзя.

### На Windows — 3 шага

1. Скачайте **Setup.exe** для своего процессора.
2. Запустите установщик: **«Установить» → «Завершить»**. Модель и .NET включены.
3. Щёлкните в поле и коротко нажмите **правый Ctrl**. Тем же нажатием остановите запись.

Если микрофон запрещён, откройте **Параметры → Конфиденциальность и безопасность → Микрофон**
и разрешите доступ классическим приложениям. Сборки без коммерческого
сертификата: Windows SmartScreen может предупредить о запуске. Повышенные
в правах программы могут не принимать ввод от обычного процесса.
Для ARM64 требуется Windows 11. Удаление — через список установленных приложений.

## Использование

Подтверждённые слова появляются во время речи. В начале записи закрепляется
выбранное поле до явной остановки. Для другого поля остановите запись и
включите её заново. В доступных редакторах возможен фоновый ввод; в остальных
текст ждёт возврата в исходное поле. Работа всех редакторов не гарантируется.
При затруднении полная итоговая фраза остаётся в истории для копирования.

В настройках можно выбрать горячую клавишу, скрыть панель и отдельно проверить
микрофон и доступ к вводу без записи. На Mac доступен запуск при входе в систему;
микрофон при запуске выключен. После 3 минут без речи диктовка останавливается.
Пока вы говорите, общего трёхминутного лимита нет.

История — последние 100 диктовок: одно включение и остановка создают одну
цельную запись, включая паузы. Она хранится локально:
`~/Library/Application Support/Golos` на Mac и `%LOCALAPPDATA%\Golos` на Windows.
Словарь содержит 110 терминов про продукты, UX, ИИ и игры. Свои слова доступны
в скрытом разделе разработчика: трижды нажмите версию внизу настроек и введите
пароль владельца. Словарь помогает, но ошибки распознавания возможны.

Рекомендуются 8–16 ГБ памяти и 2 ГБ свободного места. На слабых CPU большая
модель работает с задержкой. Отдельная видеокарта для Windows не обязательна.

## Что нового в Mac 1.7.7

- В активном поле основной ввод использует Unicode-события клавиатуры,
  сохраняя начальные пробелы между порциями текста. Обычная вставка — резерв.
- Временно скрытое поле сохраняет подтверждение начатой вставки. После возврата
  приложение сверяет результат перед повторной отправкой.
- Одинаковый URL и имя поля сами по себе не перенаправляют диктовку в другую вкладку.
- Защита от длинных циклов выдуманных повторов; модель и параметры распознавания
  сохранены от 1.7.3. Обычные короткие повторы не удаляются.
- Автозапуск при входе в macOS, сохранённые настройки и немедленное скрытие
  панели после остановки, даже когда текст ещё ждёт вставки.

Подробнее: [история изменений](CHANGELOG.md).

## Что проверено

Mac 1.7.7 (23) упакован из установленного приложения без пересборки. Владелец
принял эту сборку и запросил публикацию. Self-tests и три аудиофайла прошли;
в Chrome подтверждены 35 фрагментов, 445 символов и настоящие события ввода.
Полная регрессия не завершена: пять переходов между вкладками именно во время
ввода не подтверждены. Не выдаём этот сценарий за пройденную проверку.
[Отчёт по сборке](RELEASE-VALIDATION.md).

Intel Mac и Windows 1.7.3 проходили сборку и автоматические проверки на своих
GitHub runners. Это не заменяет живой микрофон, клавишу и все редакторы на
конкретном ПК. Статус проверки каждой платформы относится к её версии.

## Предыдущие версии и откат

Каждый выпуск хранится отдельным релизом и тегом. Старые установщики сохраняются:
[все версии](https://github.com/kurgaan5/golos/releases),
[1.7.3 для отката](https://github.com/kurgaan5/golos/releases/tag/v1.7.3).

Закройте «Голос» и установите нужную старую версию. История и настройки хранятся
отдельно; перед откатом можно скопировать их папку. На Mac после смены подписи
может потребоваться повторное разрешение ввода и микрофона. Не запускайте две версии одновременно.

## Сборка из исходников

- Mac: Xcode Command Line Tools, CMake, Python 3.8+; `bash scripts/build-macos.sh`.
- Windows: Visual Studio с C++, .NET SDK 10, CMake, Python; `pwsh scripts/build-windows.ps1 -Arch x64` или `-Arch arm64` на соответствующей системе.
- Переносимая логика: `dotnet run --project windows/Golos.Tests -c Release`.

Первичная сборка скачивает whisper.cpp 1.8.2 и модели с проверкой SHA-256
по `scripts/models.json`. Пакеты создаются в `dist/`. Модели уже включены
в скачиваемые установщики. [Лицензии компонентов](ThirdPartyNotices.txt).
