# Голос

Локальная диктовка на русском с английскими терминами. Whisper large-v3-turbo
и Silero обрабатывают звук на компьютере. Во время работы интернет, API-ключи
и подписка не нужны. Аудио не сохраняется.

## Установить

[![Установить на Mac](shared/install-mac.svg)](https://github.com/kurgaan5/golos/releases/latest/download/Golos-1.7-macOS-AppleSilicon.dmg)
[![Установить на Windows](shared/install-windows.svg)](https://github.com/kurgaan5/golos/releases/latest/download/Golos-1.7-Windows-x64-Setup.exe)

**Mac:** кнопка для M1, M2, M3, M4 и новее. **Windows:** для обычных ПК с Intel или AMD.

Другой процессор: [Mac с Intel](https://github.com/kurgaan5/golos/releases/latest/download/Golos-1.7-macOS-x86_64.dmg)
· [Windows на ARM](https://github.com/kurgaan5/golos/releases/latest/download/Golos-1.7-Windows-arm64-Setup.exe)
· [Все файлы и ZIP-архивы](https://github.com/kurgaan5/golos/releases/latest).

### На Mac — 3 шага

1. Нажмите **«Установить на Mac»**, откройте скачанный DMG и перетащите **«Голос»** в **«Программы»**.
2. Запустите «Голос» из «Программ». Разрешите микрофон и включите «Голос» в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
3. Щёлкните в нужном текстовом поле и коротко нажмите **правый ⌘**. Говорите. Нажмите его ещё раз, чтобы остановиться.

Если macOS блокирует запуск из-за отсутствия подписи Apple: после попытки запуска
откройте **Конфиденциальность и безопасность → Всё равно открыть** и подтвердите
запуск, только если скачали приложение из этого репозитория.

### На Windows — 3 шага

1. Нажмите **«Установить на Windows»** и запустите скачанный **Setup.exe**.
2. Нажмите **«Установить»**, затем **«Завершить»**. Модели и среда .NET уже включены.
3. Щёлкните в нужном текстовом поле и коротко нажмите **правый Ctrl**. Говорите. Нажмите его ещё раз, чтобы остановиться.

Если Windows показывает SmartScreen: сверьте источник скачивания и издателя;
для этой сборки без коммерческого сертификата доступно **Подробнее → Выполнить в любом случае**.
Если микрофон не работает: **Параметры → Конфиденциальность и безопасность → Микрофон → Разрешить классическим приложениям доступ к микрофону**.
Удаление — через обычный список установленных приложений Windows.

Требуется **macOS 14+**, **Windows 10 (2004+)/11 x64** или **Windows 11 ARM64**.
Windows 7/8 и 32-битные системы не поддерживаются. Рекомендуется 8–16 ГБ RAM
и 2 ГБ свободного места для установки. На старых CPU распознавание медленнее.
После установки интернет, API-ключи и подписки не нужны.
Windows автоматически выбирает доступное ускорение процессора; отдельная
видеокарта не требуется. На Intel Mac используется CPU.

## Использование

1. Выберите текстовое поле другого приложения.
2. Коротко нажмите **правый ⌘ на Mac** или **правый Ctrl на Windows**.
3. Диктуйте. Подтверждённые слова появляются во время речи.
4. Нажмите ту же клавишу для остановки. Последняя фраза будет обработана.

Поле закрепляется до остановки записи. Можно переключать окна и листать
страницы. Фоновый ввод работает, когда редактор поддерживает его через
системный API. В остальных случаях текст накапливается и вставляется после
возвращения в исходное поле. Для нового поля остановите и запустите запись заново.
Работа всех редакторов в фоне не гарантируется; расширений браузера нет.

Настройки позволяют выбрать другую клавишу и скрыть компактную панель записи.
Словарь содержит 110 терминов про продукты, UX, ИИ и игры, включая VK Play,
VK Play Cloud, roadmap и ChatGPT. Свои слова доступны в скрытом разделе:
трижды нажмите номер версии внизу настроек и введите пароль владельца.
Изменения сохраняются автоматически и применяются со следующей записи.
Словарь помогает распознаванию; ошибки в словах и пунктуации возможны.

### Разрешения и ограничения

На Mac включите приложение в «Конфиденциальность и безопасность → Универсальный
доступ», а при первом запросе разрешите микрофон. После обновления подписи
может потребоваться повторное добавление приложения. Плашка скрывается,
когда macOS подтверждает доступ.

Сборки не имеют коммерческого сертификата разработчика и нотариализации.
macOS и Windows могут запросить ручное подтверждение запуска скачанного приложения.
На Windows проверьте доступ настольных приложений к микрофону. Windows ограничивает
ввод из обычного процесса в программы, запущенные с повышенными правами.

История последних 100 фраз хранится локально: `~/Library/Application Support/Golos`
на Mac, `%LOCALAPPDATA%\Golos` на Windows. При вставке временно используется
буфер обмена. Приложение возвращает прежнее содержимое, если пользователь
не успел скопировать другое.

## Статус проверки

Mac на Apple Silicon проверен живой диктовкой владельцем. Intel Mac и Windows
собираются на соответствующих GitHub runners; тестируются загрузка моделей,
смешанная русско-английская запись и отсечение шума. Проверки CI не заменяют
проверку живого микрофона, горячей клавиши и всех редакторов на конкретном ПК.
Windows-версия — первый перенос приложения на эту платформу.
На CPU распознавание большой моделью может идти с заметной задержкой, особенно
на слабом компьютере. Мгновенный ввод на всех ПК не гарантируется.

## Собрать из исходников

- Mac: Xcode Command Line Tools, CMake, Python 3.8+. Выполните `bash scripts/build-macos.sh`.
- Windows: Visual Studio 2022/2026 с C++, CMake, .NET SDK 10, Python 3.8+.
  Для ARM64 также нужен набор Clang/LLVM в Visual Studio Installer.
  Inno Setup 6 (скрипт установит его при отсутствии).
  Выполните `pwsh scripts/build-windows.ps1 -Arch x64` или `-Arch arm64` на соответствующей системе.
- Проверки переносимой логики: `dotnet run --project windows/Golos.Tests -c Release`.

Первичная сборка скачивает whisper.cpp 1.8.2 и модели из официальных источников.
SHA-256 моделей проверяются по `scripts/models.json`. Пакеты создаются в `dist/`.
В Actions есть ручной процесс сборки, который создаёт черновик релиза после
успешных проверок всех платформ.
