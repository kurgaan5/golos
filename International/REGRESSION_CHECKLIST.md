# Проверка перед публикацией «Голоса»

Этот список создан по уже встречавшимся ошибкам. Его нужно проходить перед
каждой публикацией, включая замену установщиков существующего релиза.
Автоматический тест не заменяет проверку настоящего поля и переходов мышью.

Для каждого релиза создаётся отдельный отчёт в `validation/`. В отчёте нужны:
версия, build, commit, ОС и архитектура, SHA-256 проверенного приложения,
результат каждого применимого пункта и доказательство. Допустимые результаты:
**PASS**, **FAIL**, **НЕ ПРОВЕРЕНО**, **НЕ ПРИМЕНИМО** с объяснением.
FAIL и НЕ ПРОВЕРЕНО не считаются успешной проверкой. Нельзя заявлять проверенной
платформу или программу, на которой тест не выполнен. Публикация блокируется
непройденными обязательными проверками выпускаемых сборок.

## Обязательные проверки поведения

| ID | Что проверять | Успешный результат |
|---|---|---|
| MIC-01 | Запустить приложение, открыть/закрыть настройки, проверить разрешения; говорить без вызова | Запись не начинается, новая речь не попадает в поле или историю |
| MIC-02 | Начать диктовку, остановить, дождаться финала записанной фразы, говорить дальше | Микрофон выключен; новые слова после остановки не захватываются |
| MIC-03 | Во время записи закрыть главное окно, заблокировать Mac / отправить в сон; затем открыть/разбудить | Запись остановлена и сама не возобновляется |
| MIC-04 | 180 секунд без речи; отдельно непрерывная речь дольше 3 минут | При тишине запись остановлена, при речи продолжается |
| MIC-05 | Сон/пробуждение, смена аудиовхода, отсутствие устройства, запрещённый микрофон | Нет зависшей записи; понятное состояние и возможность проверить доступ |
| KEY-01 | Правый ⌘: одно короткое нажатие, повторный вызов, удержание; ⌘C/⌘V; выбор другой клавиши | Один старт/стоп; сочетания не включают микрофон; выбранная клавиша сохраняется |
| INPUT-01 | Начать в поле A, говорить, открыть другое приложение, прокрутить страницу и кликнуть в поле B | Текст закреплён за A; в B ничего не вводится |
| INPUT-02 | Во время той же записи сменить вкладку в том же приложении, продолжить речь, вернуться мышью в A и остановить | Всё сказанное доставлено в A один раз; очередь завершается |
| INPUT-03 | Повторить уход/возврат в A не менее 5 раз, в том числе между отправкой вставки и подтверждением | Нет потерь, повторов, случайной вставки в другую вкладку или вечного ожидания |
| INPUT-04 | В фоне исходное поле доступно для адресной записи; затем проверить редактор без такой возможности | В первом случае ввод подтверждён; во втором очередь сохранена и вставлена при возврате |
| INPUT-05 | Пересоздание поля при возврате; другое пустое поле; другая вкладка с таким же placeholder | Восстановление только при доказательстве исходного поля; пустые поля не отождествляются |
| INPUT-06 | Изменить текст/курсор вручную; очистить или отправить поле; скопировать невставленное | Ручной текст не затирается, неоднозначная вставка не воспроизводится; ручное копирование отменяет очередь |
| INPUT-07 | Проверить обычное поле, Qt AXStaticText и непрозрачный редактор | Запись/вставка не зависят от списка имён приложений; результат отражает фактическое подтверждение |
| ASR-01 | Русская фраза с паузой, product roadmap, user research, GPT, VK Play | Русский регистр и пунктуация сохранены; термины не пропадают; нет посторонних письменностей |
| ASR-02 | Последовательность противоречивых гипотез; 55 слов из 2.28 с; длинный цикл слов | Неподтверждённое не вставлено; бесконечные повторы отвергнуты |
| ASR-03 | Короткая речь, тишина, комнатный шум, щелчки и звуковые помехи | Нет ложных субтитров/циклов; сомнительный результат не выдаётся за подтверждённую речь |
| ASR-04 | Намеренно сказать «очень очень» и «да да да да» | Нормальные короткие повторы сохранены |
| ASR-05 | Потоковый тест RU/EN и запись финальной задержки | Первый ввод и завершение измерены; итог не задублирован, обработка завершается |
| HISTORY-01 | Старт → фраза → пауза → фраза → стоп; затем новый старт/стоп | Ровно одна цельная запись на каждый вызов; финалы не меняют порядок |
| HISTORY-02 | Копирование, уведомление о копировании, очистка, предел 100 записей | Копия полная; история читается после перезапуска; очистка не воскрешается поздним callback |
| UI-01 | Нажать каждую кнопку мышью, шестерёнку, крестик, настройки панели и клавиши | Всё нажимается; прокрутка не единственный работающий элемент |
| ACCESS-01 | Разрешённый/запрещённый Accessibility и микрофон, новая подпись сборки | Статусы фактические; большая плашка только без доступа; проверка не включает запись |
| LOGIN-01 | Проверить регистрацию автозапуска, вход в ОС, пробуждение и ручное отключение автозапуска | Приложение готово к клавише, микрофон выключен; ручное отключение не отменяется автоматически |
| INSTANCE-01 | Запустить вторую копию приложения, включая копию из установщика | Работает один экземпляр, микрофон и клавиша не захватываются дважды |

## Проверка программ

Для выпускаемой платформы отдельно указывать результат в Chrome, Word,
VK WorkSpace и MAX, а также в контрольном редакторе (TextEdit / Блокнот).
В каждом применимом редакторе проверить INPUT-01–03 и MIC-02. Если программы
нет или её не удалось проверить, это прямо записывается; универсальная
совместимость не заявляется. Перед релизом со сменой механизма ввода проверка
настоящих переходов между вкладками обязательна.

## Сборка и публикация

| ID | Что проверять | Успешный результат |
|---|---|---|
| BUILD-01 | Self-tests и проверки изменённой логики, сборка соответствующей архитектуры | Все обязательные проверки прошли; нет скрытых ошибок сборки |
| BUILD-02 | SHA-256 моделей, наличие моделей внутри пакета, лицензии, запуск без сети | Модели прежние либо их замена явно описана; нет API-ключа/платной зависимости |
| BUILD-03 | Финальная установленная сборка и установщики | Проверяется тот же бинарный файл, который упакован; подпись и архивы корректны |
| BUILD-04 | macOS arm64/Intel; Windows x64/arm64, разрешения и системные ссылки | Проверенные платформы перечислены честно; Windows не показывает инструкции macOS |
| RELEASE-01 | Новый тег, заметки, кнопки установки, контрольные суммы | Ссылки ведут к нужным сборкам; старые релизы и откат сохранены |
| RELEASE-02 | Сверить отчёт с этим списком непосредственно перед публикацией | Нет непройденных обязательных пунктов; ограничения указаны в release notes |

После изменения кода или подписи ранее выполненная живая проверка не переносится
автоматически на новый пакет. Финальный пакет не менять во время выдачи разрешений.
Не сбрасывать системные разрешения без отдельного разрешения владельца.
