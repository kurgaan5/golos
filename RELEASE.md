# Голос 1.7.7 — Mac с Apple Silicon

Текущая принятая владельцем сборка **1.7.7 (23)**. Упаковано то же установленное
приложение, без пересборки. Этот выпуск содержит только Mac для Apple Silicon.

## Скачать

[**Установить на Mac с M1/M2/M3/M4 и новее**](https://github.com/kurgaan5/golos/releases/download/v1.7.7/Golos-1.7.7-macOS-AppleSilicon.dmg)

Откройте DMG → перетащите «Голос» в «Программы» → запустите → разрешите микрофон
и «Универсальный доступ». Диктовка: щелчок в поле, короткий правый ⌘; ещё раз — остановка.
Нужна macOS 14+. ZIP и контрольные суммы находятся в Assets ниже.

## Изменения

- Основной ввод в активное поле через Unicode-события сохраняет пробелы между фрагментами.
- Очередь сохраняет квитанцию временно скрытого поля и сверяет результат после возврата.
- Одноимённые поля в разных вкладках не определяются только по URL и DOM ID.
- Защита от длинных циклов повторений; прежние модели Whisper и Silero уже внутри.
- Автозапуск при входе в macOS; микрофон при запуске выключен.
- Панель скрывается после Stop; история остаётся цельной на одно включение и остановку.

## Проверки и ограничения

Self-tests, три аудиофайла и поток из35 фрагментов в Chrome прошли.
Полная регрессия не завершена: переходы между вкладками именно во время ввода
не подтверждены. Работа всех редакторов не гарантируется.
[Подробный отчёт](https://github.com/kurgaan5/golos/blob/v1.7.7/RELEASE-VALIDATION.md).

Приложение имеет временную подпись без сертификата Apple и нотариализации.
macOS может предупредить о неизвестном разработчике; на рабочем Mac действуют
ограничения компании. После обновления может понадобиться выдать доступы заново.
История и настройки хранятся отдельно от приложения и сохраняются при обновлении.

## Другие платформы и откат

Обновления Intel Mac и Windows готовятся отдельно. До их выхода доступны
[проверенные пакеты1.7.3 для Intel Mac и Windows x64/ARM64](https://github.com/kurgaan5/golos/releases/tag/v1.7.3).
